# agentli

Proof-of-concept code for a minimal coding agent/harness

**⚠️ There is no sandboxing or user approval; the example is full YOLO mode and gives the LLM unrestricted bash access‼️**

## How to run?

1. Read the disclaimer above
2. `npm install` to install dependencies
2. Start one of the examples:
   - `npm run start:01` to start the basic chat
   - `npm run start:02` to start the version with the system prompt
   - `npm run start:03` to start the full version with tool support
